# Q01 页面与业务流程体验检查

页面入口清楚，登录与本人资料状态明确；完成预约不超过4次业务提交或确认，保存治疗不超过3次。

通过组件交互、接口及实际页面自动化检查，验证导航、表单提示、预约、治疗保存及结果读回。保留模拟接口与真实环境的验证边界；负责人日常使用确认体验，不强制招募参与者、培训或提交人工记录。

自动化指定场景通过，业务提交与确认次数符合目标，成功及错误提示明确；结果与后台一致，无权限绕过。不将自动化结果描述为人工实验。

执行双端类型检查、构建、组件交互测试及实际云端页面走查。真实API、受控夹具和模拟接口分别说明；已有真实微信联调作为对应版本的证据。当前开发工具连接不可用时不虚报本次原生页面测试通过。
