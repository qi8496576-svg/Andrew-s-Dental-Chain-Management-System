# 备案前本机双端联调（2026-11-18）

从项目根目录在 PowerShell 执行：

```powershell
.\tools\preview\Start-LocalIntegration.ps1
# 同时以关闭 GPU 加速方式打开微信工具并提供自动化端口：
.\tools\preview\Start-LocalIntegration.ps1 -OpenWeChat
```

管理端浏览器访问 https://localhost:19443。自签名证书仅用于该本机地址。岗位登录资料见 `D:\secrets\AndrewDental\LocalPreview\预览登录资料.txt`；总部 preview-admin 配置资源，前台 preview-frontdesk 建档、核验绑定、排班和到诊。已有全模块教师账号的资料另见同目录 `教师演示登录.txt`。口令不在源码或报告中。

微信开发者工具导入 `D:\安德鲁牙科连锁管理系统——需求分析与设计文档\apps\patient-miniprogram`，使用已有 AppID 的授权开发者账号。编译目录由 project.config.json 指向 dist/miniprogram；不要直接导入 dist。运行上述脚本后在工具中重新编译。修改 TypeScript 后也先执行脚本或 build:local。普通 build 会恢复正式域名，不能用它启动本机演示。

两个前端均通过 https://localhost:19443/api/v1 调用同一个 backend 容器，使用 adc-local-preview_mysql_data 持久化卷中的真实 MySQL 和 adc_business/adc_identity/adc_audit。关闭窗口不会清空数据。停止可使用 Docker Desktop 停止 adc-local-preview 项目；不要删除卷。

微信工具若显示空白深色界面，先保存其他项目的编辑，再使用工具菜单退出，或执行安装目录 cli.bat quit，随后运行带 -OpenWeChat 的启动命令。本次关闭 GPU 后已恢复并完成实际联调。该开关只影响工具启动；若现有工具已运行，应先退出才生效。

本机使用已有 project.private.config.json 的 urlCheck=false；公共 project.config.json 仍为 true。这是开发工具连接 localhost 和自签名证书的本地条件，不能作为正式合法域名或真机验收。AppSecret 仅挂载在后端；wx.login 和官方身份交换均为真实调用。

## 操作演示

1. 总部打开左下角齿轮，分别进入“专业资质目录”“医生与执业资质”“治疗项目与价格目录”维护基础资料；牙医须有已核验有效资质和诊所执业关系。资源详情可返回列表，保留当前筛选。前台从日常主导航进入“出诊排班”建立未来 NORMAL 班次。只使用标明虚构的本机资料。
2. 患者端微信登录，进入“本人档案绑定”，提交前台已创建档案的患者编号、出生日期和服务诊所。前台在“患者身份绑定”核对档案、本人和服务依据后批准。姓名/电话不产生自动绑定。当前微信主体已经绑定本机虚构预览患者，演示时可直接刷新本人资料。
3. 患者进入“本人预约”，选择诊所、日期及治疗，查询时段，选定时隙，核对资料及全部过敏后提交。前台在预约管理查询同一预约 ID。
4. 第一条预约可在开始前由患者填写原因取消，管理端重新读取可见 CANCELLED。再约一条，前台在“确认到诊”输入预约 ID，读取预约，填写实际服务诊所、原患者编号、出生日期和核验依据，核验后确认到诊；患者刷新可见 IN_PROGRESS。此后患者取消会被服务端拒绝。

本次通过的演示数据：2026-11-27 班次 `1141516844367136405`，治疗 `4139957967054134788`；患者取消预约 `804261213614954395`，管理端到诊预约 `2259490334298577671`。这些是已执行记录，后续演示请建立新的未来班次/预约。
