## 接口与权限

新增只读接口定义位于 [workspace-review-20261123.json](../../packages/contracts/review/workspace-review-20261123.json)。冻结的原 82 项接口契约保留原样，扩展文件记录新投影和可选字段。

- `GET /workspace/appointments`：指定既有岗位，检查该岗位 `listAppointments`、诊所及有效期；牙医范围附加本人安排与有效执业限制。按预约时间/ID 游标查询，不逐行读取患者接口。
- `GET /workspace/summary`：总部使用 `analysis.read`，其余岗位使用 `listAppointments`；服务端聚合完整范围，不以第一页代替总数。
- `GET /workspace/applied-treatments`：仅总部 `cost.verify`；返回成本归属需要的治疗关联摘要。
- `GET /appointments/{id}/fee-preview`：仅收费 `invoiceAppointment` 及该就诊诊所；只读已完成就诊的费用事实，不开放完整临床上下文。

四项接口均为 `no-store`，服务端继续逐次校验授权。新增路由已加入现有安全配置的明确白名单，并由控制器/服务检查真实 ADC 身份；匿名请求仍返回 401。

结果恢复保留原操作、请求键、对象路径、原版本及请求体 SHA-256；按当前员工隔离。刷新后先查已有收据，尚未确认时不允许用新的键发起其他业务；重新录入的原办理必须与摘要一致。成功后清理恢复元数据。浏览器未保存临床正文。
