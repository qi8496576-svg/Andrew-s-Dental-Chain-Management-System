# 正式图源一致性

当前Word的22幅嵌图与official目录及根目录“图源”中的PNG逐字节一致。18幅已确认图的SVG源与正式SVG一致，包含业务工人圆圈箭头、业务实体右下斜线、序列图嵌套激活框、类操作可见性及事件／守卫／动作标注。

Word共62页。A—D检索副本、类操作JSON、图表索引及来源校验使用相同图号和当前文件。字段表保持24表、209字段和44外键，采用已批准的精简登记、医生资料及五张费用表结构。

逐图来源及SHA-256见[word-image-audit.json](word-image-audit.json)，正式入口见[图源总览](official/index.html)。
