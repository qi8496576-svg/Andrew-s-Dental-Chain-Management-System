## 使用方法

- 管理端：https://andrewdental.cn。完整业务演示使用 cloud-demo；其口令仍在受控文件 `D:/secrets/AndrewDental/CloudIntegration/云端联调登录资料.txt`，不在仓库保存。cloud-admin 仍按已授权总部能力展示菜单。
- 排班：进入“出诊排班”，切换周概览／日视图，按日期、门店、医生筛选；点击班次查看详情、办理停诊，右上角可新增班次。待处理预约仍遵循人工停诊安排，没有自动改约或取消。
- 手机：扫描本目录 `mini-preview-final.jpg`。当前已有档案的账号直接预约；尚无档案的微信可先浏览门店、项目和真实可约时间，再在“我的→填写就诊资料”首次登记。无需患者编号或人工批准。资料保存后返回预约，重新选择真实时段并确认；提交时再次核验资格和占位。
- 首次资料包含原 Patient 必填项、本人过敏声明和确认；患者编号由服务器生成。已有历史档案的关联与换号仍走安全核实，不按姓名、手机号自动取得旧病历。
- 本地源码重新编译：使用项目 Node 24 运行 `apps/patient-miniprogram/scripts/build.mjs`，保留正式 HTTPS 地址。输出目录重建后，开发者工具若显示旧内容，需要重新索引文件、清理编译缓存并刷新模拟器。本轮已验证实际渲染文字与最终输出一致。
